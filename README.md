#  Backend Coding Test – Products API

Este projeto é uma **API REST** desenvolvida com **Spring Boot** para o gerenciamento de produtos agrícolas. A aplicação utiliza tecnologias modernas para garantir eficiência e facilidade de documentação.

---

##  TECNOLOGIAS UTILIZADAS

* **Java 17**
* **Spring Boot**
* **Spring Web**
* **Spring Data JPA**
* **H2 Database** (Banco de dados em memória)
* **Swagger (Springdoc OpenAPI)** (Documentação)
* **Maven** (Gerenciador de dependências)

---

## COMO EXECUTAR O PROJETO LOCALMENTE


### PRÉ-REQUISITOS
* Java 17 instalado
* Maven ou Maven Wrapper
